GN CVC – phone app (PWA)
========================
1. Upload ALL files in this folder to any HTTPS host (GitHub Pages, Netlify Drop, Cloudflare Pages, your web server).
2. CVC opens the link on the phone:
   Android (Chrome): menu ⋮ → Install app / Add to Home screen
   iPhone (Safari):  Share → Add to Home Screen
3. First time: log in with the MBR2 dashboard username + PIN, tap "Load data", choose the backup file (gn-backup-*.json)
   exported from GN Purchasing System > Settings > Export JSON. Only that CVC's children are kept on the phone.
4. CVC adds items, Save draft / Submit. After submit, the phone offers to send a small gn-cvc-*.json file (Telegram/WhatsApp/email).
Works offline after the first load (data and drafts stay on the phone).
